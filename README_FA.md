# پروژه اندروید SMS SMH

این پروژه برای کامپایل در GitHub Actions آماده شده است.

## ساخت APK با GitHub

1. فایل ZIP را از حالت فشرده خارج کنید.
2. وارد GitHub شوید و یک Repository جدید بسازید (ترجیحاً با نام `SMS-SMH`).
3. تمام محتویات پوشه `SMS-SMH` را در ریشه Repository بارگذاری کنید؛ خود پوشه `SMS-SMH` را به‌عنوان یک پوشه تو در تو بارگذاری نکنید.
4. فایل‌ها را با گزینه **Commit changes** ثبت کنید.
5. وارد زبانه **Actions** شوید. گردش‌کار **Build SMS SMH APK** به‌صورت خودکار اجرا می‌شود.
6. پس از سبز شدن وضعیت اجرا، همان اجرای Workflow را باز کنید و از قسمت **Artifacts** فایل `SMS-SMH-debug-apk` را دانلود کنید.
7. ZIP دانلودشده را باز کنید؛ فایل `app-debug.apk` داخل آن است.

برای اجرای دستی کامپایل: زبانه **Actions** ← **Build SMS SMH APK** ← **Run workflow**.

## محیط ساخت

- JDK 17
- Gradle 8.7
- Android Gradle Plugin 8.6.1
- Kotlin Android Plugin 2.0.21
- Android compileSdk 35

## نکات مهم نسخه فعلی

- این خروجی، APK آزمایشی (Debug) است و برای انتشار عمومی امضای Release ندارد.
- برنامه برای مدیریت دریافت پیامک باید با تأیید کاربر به‌عنوان برنامه پیش‌فرض SMS انتخاب شود.
- پیامک‌های موجود گوشی با نصب برنامه پاک نمی‌شوند؛ برنامه فعلی آن‌ها را از صندوق پیامک اندروید می‌خواند.
- فیلتر تبلیغات در این نسخه مبتنی بر عبارت‌ها و فهرست فرستندگان مورد اعتماد/مسدودشده است؛ تشخیص هوشمند مبتنی بر مدل یادگیری هنوز پیاده‌سازی نشده است.
- دریافت MMS در این نسخه پیاده‌سازی نشده است؛ تمرکز نسخه فعلی روی SMS است.
- پیش از استفاده روزمره، APK باید روی گوشی واقعی آزمایش شود.


## تغییرات نسخه اصلاح‌شده

- تم روشن و تیره به‌صورت خودکار از تنظیمات ظاهری اندروید پیروی می‌کند.
- آرشیو کامل پیامک‌ها بدون سقف ۵۰۰۰تایی در اولین ورود و در رشته پس‌زمینه خوانده می‌شود.
- کل آرشیو، خلاصه گفتگوها و نمایه پیام‌های هر شماره در حافظه فرایند نگه‌داری می‌شوند؛ رفت‌وبرگشت بین صندوق و گفتگوها دوباره دیتابیس پیامک اندروید را اسکن نمی‌کند.
- دکمه «بارگذاری مجدد پیام‌ها» برای تازه‌سازی دستی آرشیو پس از دریافت یا تغییر پیامک‌ها در منوی بالا اضافه شده است.
- گفتگوها بر اساس جدیدترین پیام مرتب می‌شوند؛ هنگام بازکردن گفتگو، جدیدترین پیام‌ها در پایین صفحه دیده می‌شوند.
- در هر گفتگو ابتدا ۱۰۰ پیام آخر نمایش داده می‌شود و با دکمه «نمایش پیام‌های قدیمی‌تر» می‌توان به تمام تاریخچه رسید.
- نگه‌داشتن انگشت روی ردیف گفتگو یا حباب پیام، منوی عملیات شامل حذف، کپی، انتقال به تبلیغات و مسدودسازی را باز می‌کند.
- تنظیمات فیلتر شامل تشخیص خودکار تبلیغات، شماره‌های مسدود، متن‌های مسدود، کلمات تبلیغاتی سفارشی و فرستندگان مجاز است.
- فهرست قواعد از تنظیمات قابل افزودن، حذف تکی (لمس طولانی روی فهرست) و پاک‌کردن کامل است.
- پیام‌های منتقل‌شده به تبلیغات قابلیت بازیابی به صندوق یا حذف دائمی دارند.
- نوار پایین با inset نوار ناوبری اندروید فاصله می‌گیرد.
